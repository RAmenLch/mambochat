# CHANGELOG

## [1.3.1] - 2026-08-26
**多模态调用增强、OpenRouter 图像模型参数、桌面端体验优化与多项修复**。

### 🖼️ 多模态调用增强

- **多模态描述 (Multimodal Describer)**：为图片 / 音频 / 视频 / 文档（PDF/PPT 等）四种模态分别绑定一个支持该模态的模型
    - 主模型原生支持的模态默认透传直读；绑定描述模型后，主模型不支持的对应模态文件会先由描述模型生成描述文本
    - 未绑定任何描述模型的模态将返回显式拒绝文本，避免多模态内容直通模型 API 报错
    - 可在 Mambo 智能体编辑器"专属配置"中按模态逐个绑定描述模型
- **read 工具超时增强**：启用多模态描述后可额外配置 read 工具的读取超时（总超时 = 60s + 配置值），应对大图片/音视频/文档的读取
- **多模态工具结果媒体引用**：read 等内置工具读取的图片/音视频/PDF 以媒体引用形式落库，上下文重建时可精确还原多模态内容，前端可流畅展示

### 🖌️ OpenRouter 图像模型

- **补充并修复 OpenRouter 图像生成模型参数**：新增宽高比、质量、输出格式、背景、压缩率、尺寸等参数，经 `extra_body.image_config` 传递
- 兼容服务商 `supported_parameters` 的 list 与 dict 两种返回格式，参数可被自动匹配挂载到图像模型（如 gemini-3-pro-image-preview、gpt-5-image-mini）

### 💻 桌面端体验优化

- **data 文件夹可迁移**：桌面端新增 data 文件夹迁移能力，可调整数据存储位置
- **API Client 支持创建多个**：桌面端 API 客户端从单个升级为可管理多个客户端（可命名、独立注册/启动/停止/重启、支持各自随启动自启），并兼容迁移旧的单客户端配置
- **启动与刷新速度优化**：后端优化启动速度（延迟加载重依赖、预加载多模态相关模块），桌面端优化启动与刷新速度

### 🔧 修复与优化

- **路径补全增强**：为 api / ssh / local 类型的 backend 提供逐级路径补全（含 /workspace、/.mambo 虚拟空间），带实例缓存、目录缓存与子文件夹后台预热；SSH/API 慢网络下超时兜底、断线自愈
- **会话默认名称显示修复**：修复会话设置的会话默认名称显示问题
- **自动摘要报错修复**：修复自动摘要触发的报错
- **apibackend 不一致修复**：修复 API Backend 配置不一致问题
- **docker 启动报错修复**：修复 Docker 环境启动报错
