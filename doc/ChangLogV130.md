# CHANGELOG

## [1.3.0] - 2026-08-11
**Mambo 智能体全面上线、新增命令行工具、AI 文件操作与资源版本化**。

### 🤖 全新的 Mambo 智能体(取代 DeepAgent)

- 新增 **Mambo 类型智能体**,旧的 DeepAgent 正式退役
- **实时文件展示**(默认开启):新增 show 工具,AI 读取文件/图片时可实时展示给你看
- **AI 安全预审**(可选):可指定专用审核模型,AI 先预审工具调用,危险操作才需要你确认
- **资源版本自动快照**(可选):AI 每次写入/修改/删除文件自动留版本,随时可回滚
- **长期记忆**(可选):可挂载专属记忆资源,AI 能记住长期偏好,并把新学到的内容写回记忆
- **对话自动压缩**(可选):链式摘要逐轮合并不覆盖、相比DeepAgents中文/日文统计更准确,摘要阈值可配置,摘要文本可修改
- **计划与摘要联动**(默认开启):多步骤任务使用结构化计划;开启自动压缩后,即使对话被压缩,**进行中的计划也不会丢**
- **MCP 智能接入**:工具少于 15 个时直接暴露给 AI;工具很多时自动切换为"按需查询"模式,避免撑爆提示词
- 稳定性:悬空工具调用自动修补、多模态模型工具消息自动重排

#### Mambo-Agents 具有更强的扩展性和安全性
提供 SshBackend / LocalBackend / ResourceBackend/ ApiBackend / StoreBackend
具有会话专属空间 /.mambo,避免污染工作区
工作区 挂载至 /workspace,并严格限制对 / 操作 避免模型幻觉触发危险操作


### 💻 新增命令行工具 `mambo`
用于提供给 LLM 配置MamboChat 就不用自己动手了

- **服务商/模型**:增删改查、测试连通性、设置默认模型(自动补全模型能力信息)
- **资源**:像操作文件系统一样 `ls` / `cat` / `write` / `mkdir` / `mv` / `rm`,支持全局搜索
- **Skill**:增删、校验规范、从文件或 GitHub 导入
- **MCP**:增删、测试连接、同步工具列表、开关工具、配置审核
- **Agent**:创建/移动/复制/挂载资源、**导出/导入 `.mamboagent` 包**、管理子智能体
- **Backend**:管理 SSH / API / Resource / Local 四种后端,一键查看 SSH 公钥

### 📦 导入导出强化
- **智能体导入导出** 一个智能体(含子智能体)可打包成 **`.mamboagent` 文件**,自动带走它依赖的模型、资源、MCP、后端配置
- **会话导入导出** 整个聊天会话可导出为JSON文件再导入,方便备份与迁移 

### 🌐 优化联网功能
- 会话设置新增联网搜索开关(支持"仅读网页"和"搜索+读网页"两种模式)
- AI 可自行检索网页并阅读内容来回答;网络请求支持**走代理**访问受限站点
- 原先功能稀烂的独立部署的 `ddgs` 搜索服务已移除

### ⚙️ 配置国产模型更省心

- 接入 GLM、DeepSeek、Kimi 等模型时,系统**自动识别模型能力**(上下文长度、是否支持看图、是否支持思考模式),无需手动填参数
- 支持设置模型默认参数;DeepSeek 思考开关可在智能体页面直接配置

### 🔧 体验优化

- **移动端大改版**:会话、设置、智能体、MCP、模型等页面全面重构
- **桌面端增强**:新增本地 API 客户端(Windows 可直接连接 API 后端)、打包安装优化
- **多模态**:强化生成时图片显示,图片/音频回复展示更流畅
- **Skills**:文件/GitHub 导入增强、批量导入、新增预览与保存
- **工具调用展示**:增强工具气泡、子智能体执行面板(实时查看子智能体步骤)
- **性能**:启动更快、Docker 部署优化、清理孤儿文件减少磁盘占用
- **编码体验大幅优化** 当前 MamboChat 是一个合格的vite code 编码工具, 实践上起码比 CodeB*ddy 强
- **角色扮演体验大幅优化** 当前 MamboAgent 支持多种设定读取能力,扮演skills以及远程/本地图片展示能力,同时支持外挂生图MCP
