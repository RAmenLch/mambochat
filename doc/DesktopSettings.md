## 桌面端设置指南

MamboChat 桌面客户端提供了独立的设置窗口，用于管理运行模式、后端服务等配置。下面将介绍如何使用各项功能。

---

### 打开设置窗口

你可以在应用主界面的托盘菜单中打开它。

![桌面端设置窗口](img/桌面端.png)

> **首次启动提示**：第一次启动本地模式时，系统需要解压内嵌的 Python 运行时环境（约数百 MB），该过程可能需要几分钟时间，请耐心等待。解压完成后，后续启动将直接使用已解压的环境，不再重复此过程。

---

### 1. 选择运行模式

页面顶部会显示当前使用的运行模式，提供两种选择：

| 模式 | 说明 |
|------|------|
| **本地模式** | 使用内嵌的 Python 环境，在本机自动启动后端服务。数据存储在本地，无需额外安装任何东西，开箱即用 |
| **远程模式** | 连接到远程服务器上已运行的 MamboChat 后端。适用于多设备共享或服务器部署场景 |

![桌面端-本地模式](img/桌面端_本地模式.png)

![桌面端-远程模式](img/桌面端_远程模式.png)

---

### 2. 本地模式配置

选择"本地模式"后，你可以配置以下选项：

**基本设置**

- **Host（地址）**：后端监听地址，默认为 `127.0.0.1`（仅本机访问）
- **端口范围**：默认 `8000 — 8010`。如果起始端口被占用，系统会自动尝试下一个端口
- **Python 路径**：内嵌 Python 解释器的路径，通常无需修改
- **数据目录**：数据库与上传文件的存储位置。默认位于 `%AppData%\mambochat-desktop\data`（C 盘）。由于数据库可能膨胀较大，建议将其指向空间充足的磁盘，避免 C 盘被占满

![桌面端-数据目录](img/桌面端_数据目录.png)

**切换数据目录时：**

1. 点击 **选择文件夹…** 或手动输入一个路径（留空则恢复默认位置）
2. 点击 **保存并应用**，系统会先停止后端，并根据**目标目录的状态**弹出不同的提示：

**① 目标目录为空或不存在（最常见）**

| 选项 | 说明 |
|------|------|
| **迁移并删除旧数据** | 将 `DB` 与 `uploads` 完整复制到新目录，随后删除旧目录以释放磁盘空间（推荐，但请确保复制成功后再操作） |
| **仅迁移** | 复制数据到新目录，旧目录保留 |
| **取消** | 放弃本次更改，数据目录保持不变 |

**② 目标目录已包含 MamboChat 数据（检测到 `DB/mambo.dat`）**

| 选项 | 说明 |
|------|------|
| **直接使用目标数据** | 不迁移，直接切换到目标目录里的那份数据（适合在多个数据集之间切换） |
| **迁移并删除旧数据** | 用当前数据覆盖目标目录后删除旧目录 |
| **仅迁移** | 用当前数据覆盖目标目录，旧目录保留 |
| **取消** | 放弃本次更改 |

> ⚠️ 选择"迁移"会**覆盖**目标目录中已有的 MamboChat 数据，请谨慎操作。

**③ 目标目录非空但无 MamboChat 数据**

放行，但会提示：仅会在其中创建 `DB/` 与 `uploads/` 子目录，不影响已有的其他文件。

3. 迁移完成后后端会自动以新目录重启，聊天记录与上传文件均不受影响。

> **注意**：迁移会复制大量数据（视数据库大小而定），期间请勿关闭应用。建议迁移前先停止后端（或直接通过保存流程自动完成）。

**外部访问（可选）**

如果你希望局域网内的其他设备也能访问你的 MamboChat，可以开启"允许外部访问"：

- 开启后，后端和前端网关将绑定到 `0.0.0.0`
- 页面会显示当前机器的局域网地址，其他设备通过该地址即可访问
- 你还可以自定义网关端口（默认 `5173`）

> **安全提示**：开启外部访问后，同一网络内的设备都可以访问你的 MamboChat 实例，请确保你处于可信的网络环境中。

---

### 3. 远程模式配置

选择"远程模式"后，只需填写一项：

- **服务器 URL**：远程后端的完整地址，格式为 `http://<IP 或域名>:<端口>`，例如 `http://192.168.1.100:8000`

填写完成后，可以点击 **测试连接** 按钮，验证该地址是否可达。

---

### 4. 后端服务管理（本地模式）

在本地模式下，页面下方提供了后端进程的管理功能：

| 状态 | 说明 |
|------|------|
| ● 运行中 | 后端正常运行中，显示实际端口号和进程 ID |
| ○ 已停止 | 后端未运行 |
| ● 启动中... | 正在启动过程中，请稍候 |
| ● 错误 | 启动或运行时出错，会显示具体错误信息 |

**控制按钮说明：**

- **▶ 启动**：使用当前配置启动后端服务
- **■ 停止**：停止正在运行的后端服务
- **↻ 重启**：停止后重新启动（修改配置后建议使用此按钮使配置生效）

> 切换到远程模式时，本地后端会自动停止；切回本地模式时需要手动点击启动。

---

### 5. 保存配置

完成所有配置后，点击 **保存配置** 按钮，设置会被持久化保存，并根据需要自动重启后端或网关服务以使配置生效。
