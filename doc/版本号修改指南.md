# 版本号修改指南

每次发版只需修改以下文件：

## 1. 后端版本
修改 `backend/_version.txt`（如 `1.3.0` → `1.3.1`）
> 自动同步：pyproject.toml、FastAPI 版本、CLI `--version`、导出包版本、uv.lock

## 2. 前端 / 桌面版本
修改 `frontend/mambo/package.json` 的 `version` 字段
> 自动同步：关于弹窗、package-lock.json、桌面端版本及安装包名（桌面构建时自动同步，无需手动改）

## 3. README badge（手动）
修改 `README.md`、`doc/README_EN.md` 第 3 行 badge 里的版本号

## 不要改
- `SUPPORTED_FORMAT_VERSION` / `EXPORT_FORMAT_VERSION`（导入导出格式版本，仅格式规范变更才 bump）
- 锁文件 / dist / release 中的第三方依赖版本（构建时自动更新）
